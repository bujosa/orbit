# Roadmap

## Next

- macOS login-item registration through `SMAppService`.
- Tailscale discovery and guided SSH pairing with verified fingerprints.
- Expiry reminders and supported provider usage windows.
- Custom T3 provider bindings behind a versioned adapter.
- Local health history with bounded retention and redacted export.
- End-to-end sign-in recovery using disposable sessions.
- Developer ID signing, notarization, and verified downloads.

## Later

- Optional monitoring on an always-on host, independent of the laptop.
- Explicit service recovery, wake support, and maintenance actions.
- iPhone/iPad companion with its own trust model.

Open-source publication requires the owner's explicit decision after implementation and security review. Nothing changes visibility automatically.
